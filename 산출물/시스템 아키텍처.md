### 자연어의 고유 특징

1. 데이터 표현 다양성
    1. 형식 다양 : 문장, 단락, 대화, 시, 소설 등
    2. 언어 다양 : 여러 언어 존재
    3. 표현 다양 : 형태소, 구문, 의미 단위까지 포함
2. 특징적 요소
    1. 중의성
        1. 표현이 하나의 의미로 고정되지 않음
    2. 오탈자, 약어
        1. 맞춤법, 줄임말이 빈번, 비표준 표현 존재
    3. 이모티콘/기호
        1. 글이 아닌 감정 등의 반응 전달 가능
    4. 문맥 의존성
        1. 동일 표현이 상황에 따라 의미 변화, 앞뒤, 상황맥락 필요
    5. 형태소 구문 의미 단위
        1. 문장 구성요소가 모두 의미를 갖는 것은 아님
    
    자연어 처리에서는 문장을 형태소 단위로 분해하여 의미 있는 단어를 추출하고, 문맥을 고려하여 실제 의미를 파악하는 과정이 중요하다.
    

### 다양한 언와 환경적 다양성

1. 언어별
    1. 문법구조 차이
    2. 어순 차이
2. 시간에 따른 변화
    1. 시대, 세대에 따라 표현 변화
    2. 유행어 vs 소멸어 존재
3. 번역, 뉘앙스 문제
    1. 관용적 표현, 문맥, 감정에 따라 의미 달라짐

번역 과정에서도 단어의 사전적 의미만으로는 충분하지 않다. 문맥, 감정, 문화적 배경에 따라 의미와 뉘앙스가 달라질 수 있으므로, 자연어 처리에서는 단어뿐 아니라 문장 전체의 맥락을 함께 분석하는 것이 중요하다.

### 자연어의 시각화

1. 특징
    1. 시각화의 어려움
    2. 대표 시각화 방식 : 워드 클라우드
        1. 단어의 등장 빈도·비중을 글자 크기로 표시
        2. 자연어 표현을 시각적으로 보여주는 대표 기법
2. 데이터 분석을 위한 전처리
    1. 원본 텍스트를 문장 → 단어 → 의미 요소로 분해
    2. 의미 있는 요소만 남겨 분석
3. 음성 데이터와의 차이
    1. 음성도 자연어 데이터가 맞음
    2. 발음, 억양 포함 → 텍스트 변환 과정 필요해 분석 방법이 다름

자연어를 분석하기 위해서는 먼저 문장을 단어와 형태소로 분해하고, 조사나 접속사와 같은 불필요한 단어(불용어)를 제거하는 전처리 과정이 필요하다.

### 한글 자연어 전처리

(1) 토큰화

- 토큰화 단위에 따른 분류
    - 문장(Sentence) 단위 토큰화
    - 단어(Word) 단위 토큰화
- 단어 단위 토큰화 방법에 따른 분류
    - 어절 단위 : 띄어쓰기 단위, 영문에 적합
    - 형태소 단위 : 한글에 적합
    - Subword : 형태소와 유사, 의미 대신 통계적 방법 적용

(2)불용어 제거

- 문장이나 문서의 특징을 표현하는데 불필요한 단어를 제거하는 단계
    - 불용어 사전을 활용하여 제거
    - 불용어 사전 관리

한국어에서는 띄어쓰기가 잘못되어 있는 경우가 많다.

띄어쓰기를 자동으로 복원하면 형태소 분석과 감성 분석의 정확도를 높일 수 있다.

- 띄어쓰기 적용을 위한 PyKoSpacing 설치

```
원문 텍스트
→ 문장 단위 토큰화
→ 단어 단위 토큰화
→ 불용어 사전 불러오기
→ 불용어 제거
→ 분석에 필요한 단어만 남김
```

## 영어, 한글 형태소 분석

1. 형태소 분석이란?

형태소는 의미를 가지는 가장 작은 언어 단위이다.

하나의 단어 안에도 여러 개의 형태소가 존재할 수 있다.

1. 형태소 분석이 필요한 이유

한국어는 조사와 어미가 매우 다양하다.

형태소 분석을 수행하면 단어들을 동일한 의미 계열로 처리

이 과정을 통해 컴퓨터는 문장의 문법 구조를 이해할 수 있다.

1. 품사란?

단어의 역할을 의미한다.

1. LLM에서 형태소 분석의 역할

최근의 LLM은 형태소 대신 Subword 기반 토크나이저를 많이 사용한다.

**BPE**

자주 등장하는 문자 조합을 하나의 토큰으로 결합

**WordPiece**

자주 사용되는 단어 조각을 학습

**SetencePiece**

공백을 포함하여 토큰을 생성하는 방식

1. 자연어 데이터 품질 향상 방법

    4. 데이터 균형 유지

### 형태소 분석 실습

**형태소와 형태소 분석**

형태소

- 토큰
- 형태소는 언어학에서 일정한 의미가 있는 가장 작은 말의 단위로 발화체 내에서 따로 떼어낼 수 있는 것을 말한다. 즉, 더 분석하면 뜻이 없어지는 말의 단위이다.
- 어절보다는 작지만 그래도 의미를 가진 단위

형태소 분석

- 토큰화
- 텍스트 토큰화란 말뭉치로부터 토큰을 분리하는 작업

문장 토큰화

- 문장의 마침표, 개행문자, 느낌표, 물음표 등 문장의 마지막을 뜻하는 기호에 따라 분리하는 것
- 한국어는 보편적으로 한글 '형태소 분석기'로 토큰화를 한다.
