# Ecobot 데이터 수집 및 전처리 아키텍처 요약

## 1. 수집된 데이터 현황 (총 24개 문서)

Ecobot은 분리배출 및 환경 법령 관련 답변의 정확성을 높이기 위해 법령 9건과 가이드 15건의 데이터를 구축하여 활용합니다.

* **법령 데이터 (`data/laws/`, 9건)**

* `폐기물관리법`, `자원의 절약과 재활용촉진에 관한 법률` 및 각각의 시행령·시행규칙, `순환경제사회 전환 촉진법`, `분리배출 표시에 관한 지침` 등


* **한계 및 유의사항**: 별표 데이터가 대부분 미수록되어 있거나 요약 재구성되어 있어, 정확한 수치나 표 인용이 필요할 때는 `law.go.kr` 원문 대조가 필요합니다.




* **가이드 데이터 (`data/guide/`, 15건)**

* **지역 가이드 (6건 + 전국 공통 1건)**: 서울시, 천안시, 부산 남구, 세종시, 인천 미추홀구, 제주특별자치도 및 환경부 공통 기준


* **공통 주제 가이드 (8건)**: 대형폐기물 배출절차, 폐가전 무상방문수거, 유해폐기물 배출, 음식물쓰레기 구분기준, 일회용품 줄이기, 에너지절약, 탄소중립, 친환경 소비생활


* **작성 원칙**: 지자체마다 다른 수수료 등의 수치는 배제하고 "지자체 확인"으로 안내하며, 문서 머리에 작성 기준일을 명시합니다.

## 2. 데이터 수집 및 검색 튜닝 방법

* **법령 수집 및 정제**: `law.go.kr`의 PDF를 미러 링크 등을 통해 수집하며, 머리말·꼬리말·부칙·시행예정 중복판을 제거하고 줄바꿈 시 깨진 공백을 전수 복원합니다.


* **가이드 작성 및 튜닝 (2차 정제)**:
* 검색 및 답변 품질을 높이기 위해 원문 의미를 유지하며 청킹에 유리하게 재구성합니다.


* 사용자 검색 표현을 반영한 **동의어 병기**, 블록 하나만 읽어도 답이 되게 하는 **청크 단위 자기완결성**, 대비형 정보의 통합 배치를 원칙으로 합니다.


* *주의*: 텍스트 블록 구조 변경 시 청크 경계가 달라지므로, 반드시 재시드(`python -m scripts.seed_docs`)와 골든셋 평가를 수행해야 합니다.

## 3. 데이터 전처리 및 적재 규칙

* **텍스트 추출 (`seed_docs.py`)**:
* 지원 형식은 `.txt`, `.md`, `.pdf` 이며, PDF는 페이지별 텍스트 추출 후 정제·병합합니다.


* 텍스트 형식(`.txt`, `.md`)은 가이드 내 `[품목]` 블록 구분이 깨지는 것을 방지하기 위해 별도의 정제 없이 그대로 읽습니다.




* **법령 청킹 (`chunk_service.py`)**:
* `제N조(` 패턴을 기준으로 분할하여 "조문 하나 = 청크 하나"의 구조로 적재합니다.




* **지역(region) 메타데이터 매핑 (`seed_docs.py` & `chunk_service.py`)**:
* 문서 제목의 지역 키워드를 감지하여 `region` 컬럼에 매핑합니다 (`서울` ➔ `seoul`, `천안` ➔ `cheonan` 등).


* 매칭되지 않는 법령이나 공통 가이드의 `NULL` 값은 청크 생성 단계에서 검색 필터 호환을 위해 `"common"` 문자열로 자동 변환됩니다.




* **적재 제외 규칙**:
* 밑줄(`_`)로 시작하는 파일이나 `readme`, `notes`, `메모` 등의 스템을 가진 파일은 적재 대상에서 제외됩니다.

## 4. 최종 데이터베이스 스키마 (`documents` 테이블)

법령 및 가이드 원문을 저장하는 핵심 테이블인 `documents`의 주요 필드 구조입니다.

| 필드명 | 데이터 타입 | 설명 |
| --- | --- | --- |
| **`title`** | VARCHAR(255) | 문서 제목 (첫 줄의 `[` 포함 80자 이하 규칙 또는 파일명으로 추출)

 |
| **`content` / `content_text**` | LONGTEXT | 문서 원문. MySQL 기본 TEXT 한계(65,535바이트) 극복을 위해 `with_variant`를 적용하여 `LONGTEXT`로 저장

 |
| **`source_type`** | ENUM | 문서 소스 유형 (`law` | `guide` | `manual` 등)

 |
| **`region`** | VARCHAR(50), NULL 허용 | 지역 코드. `NULL`인 경우 전국 공통(`common`)으로 변환 처리

 |
| **`source_url`** | VARCHAR(500), NULL 허용 | 원본 출처 URL (현재 컬럼만 존재하며 값은 비어있는 상태)

 |
